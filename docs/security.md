# 安全边界

## 网络

默认 `publicOnly`，拒绝私网、loopback、链路本地、保留地址和 IPv6 过渡地址。
IP 字面量在请求前检查；域名在实际连接 DNS 解析阶段检查，验证结果直接用于连接。
逐跳检查重定向，关闭系统代理，避免代理导致目标验证失效。
TLS 使用内置公共根证书，不依赖 Android JVM 证书验证器初始化；不关闭证书验证。

`allowPrivate` 只供可信本机场景显式配置，不能作为 Express 请求参数交给用户选择。
应用仍应通过网络防火墙／容器 egress 隔离限制后端权限；SDK 不替代基础设施安全。
Express 后端还必须负责认证、限流、输入大小和会话配额。

## 凭据与规则

- Cookie Jar 按任务创建，规则只收到对应站点配置，不共享用户或站点的登录态。
- Cookie 配置、解析 options 和底层 HTTP 错误不会进入 Debug／错误输出。
- SDK 不负责自动登录、解验证码，也不会获得其他 App 的会话。
- JS 不开放文件系统、进程、任意动态模块或可绕过策略的通用网络 API。
- CDN 只接受 HTTPS、限制体积并校验摘要；摘要不等于签名认证，CDN 必须可信。
- JS 引擎设置内存、栈和中断检查；取消包括网络等待和同步执行。

## 发布前

需要核实保留的第三方来源中授权不明确的项目，并验证各目标平台原生依赖。
不能把匿名样本通过、静态分析通过或底层声称支持平台描述为真实网站成功率保证。
